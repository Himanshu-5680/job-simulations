## 📌 Overview

A virtual job simulation focused on **data analytics and commercial insights** for a retail client. I worked with transaction datasets to understand customer behaviour, tested a store layout trial, and turned the findings into recommendations for the Category Manager.

## ✅ What I Did

1. **Data preparation and customer analytics:** cleaned and validated transaction data and extracted commercial insights from it.
2. **Trial store analysis:** identified benchmark stores for uplift testing of trial store layouts, so decisions could be evidence-based.
3. **Reporting:** used the earlier analysis to create a comprehensive report for the Category Manager, supporting strategic decisions.
