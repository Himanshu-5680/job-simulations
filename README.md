> Real-world data analytics tasks from leading companies, completed through **Forage virtual job simulations**. Each folder contains my approach, deliverables and what I learned.

These simulations are self-paced virtual programs designed around the kind of work analysts do on the job: cleaning messy data, building dashboards, testing business ideas and presenting recommendations to stakeholders.
